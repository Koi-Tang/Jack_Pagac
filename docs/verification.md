# 1.0.0 验证记录

验证日期：2026-11-02。

## 插件与安装

- Portable manifest 通过官方 Agent Plugins 1.0.0 JSON Schema；Codex 兼容 manifest 路径和资源存在性已核对。
- 当前 Codex CLI 通过只读、临时 marketplace 配置成功识别 `codex-shorekeeper-startup@codex-shorekeeper`，版本 `1.0.0`。未安装到测试者的正式插件环境。
- 技能通过 frontmatter 校验，中文文件为 UTF-8；供 Windows PowerShell 5.1 读取的脚本带 UTF-8 BOM。
- 24 个部署文件按 SHA-256 与大小校验，包含随安装复制的代码许可和素材说明。Git 属性禁止改写 payload 的换行，避免下载后哈希变化。

Windows PowerShell 5.1 下完成 9 项隔离生命周期场景，16 次管理调用，全部通过：

1. 部署清单完整性。
2. 默认安装、重复安装，以及无关文件保留。
3. 非本项目拥有的非空目录保护。
4. 显式替换官方快捷方式、合成版本升级、原入口按原 SHA-256 恢复。
5. 用户修改新增快捷方式时拒绝卸载。
6. 用户修改被替换快捷方式时拒绝卸载。
7. 同名非官方快捷方式冲突保护。
8. 损坏包在任何快捷方式修改前被拒绝。
9. 移走源插件后，安装目录内管理脚本仍可独立卸载并恢复原入口。

这些测试只使用临时安装目录、临时桌面与模拟快捷方式，跳过真实应用检查，不启动或结束真实客户端。测试脚本随仓库提供，运行后报告留在本地测试目录；含本机路径的原始报告未公开。

离线浏览器验证：预加载后等待 4.2 秒仍暂停在第 0 帧；收到模拟原生可见确认后从接近 0 秒开播；约 5 秒结束；动画层、页面动画及临时样式均清理，无页面错误。

启动和转场协议沿用此前在官方 Windows Codex `26.1027.6604.0` 测过的 v3：冷启动、最小化恢复、托盘隐藏恢复、运行中窗口均收到第 0 帧起播回执。此次插件打包未重新打开使用者的当前会话；`overlay.js`、`launch.ps1`、`inject.mjs`、`StartupGate.cs` 与已验证版本逐字节一致。C# 辅助程序从随包源代码重编译，入口使用自绘图标。

真实应用内部界面的长期兼容性仍取决于官方更新；模拟页面和安装生命周期测试不替代每个未来客户端版本的实际启动验证。
